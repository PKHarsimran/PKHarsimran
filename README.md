## Security & intelligence

### [SwiftIOC](https://github.com/PKHarsimran/SwiftIOC-Automated-Threat-Intelligence-Collector)

Collect, normalize, and investigate threat intelligence. SwiftIOC combines a Python collector with a browser dashboard for reviewing indicators of compromise and vulnerability reports, inspecting source evidence, and exporting data for other tools.

**Built for:** threat research, IOC review, and repeatable intelligence collection.  
[Explore the code](https://github.com/PKHarsimran/SwiftIOC-Automated-Threat-Intelligence-Collector) · [Try the live dashboard](https://harsim.ca/SwiftIOC-Automated-Threat-Intelligence-Collector/)

### [IOC Inspector](https://github.com/PKHarsimran/IOC-Inspector)

Triage suspicious PDFs and Office documents with static analysis, IOC extraction, and optional threat enrichment. Export findings in Markdown, JSON, or CSV for investigation notes and downstream workflows.

**Built for:** document triage and structured reporting.  
[Explore the code](https://github.com/PKHarsimran/IOC-Inspector)

## Tools I build

### [Website Downloader CLI](https://github.com/PKHarsimran/website-downloader)

Create browsable offline mirrors of websites you're authorized to archive. This Python CLI rewrites links and assets for offline use, supports incremental updates, and offers optional JavaScript rendering with Playwright.

**Built for:** offline documentation, site backups, and repeatable archiving.  
[Explore the code](https://github.com/PKHarsimran/website-downloader) · [Read the guide](https://github.com/PKHarsimran/website-downloader/wiki)
