# Toolkit icons

Local SVGs from [Simple Icons](https://github.com/simple-icons/simple-icons), pinned to `4d29a35c954699b389a834aacc97dd6e7e74143c`. Source URLs and SHA-256 hashes are in sources.json. The CC0 license is included. Cortex XDR uses its parent Palo Alto Networks brand mark.

The toolkit generator embeds the paths in each panel and colours them to match the profile. No runtime CDN requests are needed. Refresh deliberately with `python scripts/vendor_tool_icons.py`.

The small Splunk chip uses an original terminal chevron for legibility in place of its full wordmark.
